# 성경퀴즈 실시간 대시보드

메인 컴퓨터로 진행하고 학생들은 스마트폰으로 참여합니다.
성경 문제 46개와 미니게임 6개(총 52장)가 선택판에 카드로 깔리고, 선생님이 고르는 순서대로 진행됩니다.

---

## 실행하기

기존 폴더의 파일을 **모두 새 파일로 덮어쓴 뒤** `실행하기(윈도우).bat`을 더블클릭하세요.
`npm install`은 이미 하셨으니 다시 안 하셔도 됩니다.

대시보드를 열면 **"클릭해서 시작하기"** 화면이 뜹니다. 한 번 클릭하면 배경음악이 켜집니다 (브라우저가 소리를 내려면 클릭이 한 번 필요합니다).
**F 키**를 누르면 전체화면이 됩니다.

---

## 진행 방식 — 선택판

`퀴즈 시작`을 누르면 **선택판**이 나옵니다. 남은 문제가 카드로 깔려 있고, 카드에는 **키워드**(인물·장소·사건·숫자·말씀·성경책·넌센스), **난이도(★)**, **배점**이 적혀 있습니다. 미니게임은 보라색 카드입니다.

1. 카드를 **클릭**하면 3초짜리 **예고 화면**이 뜹니다. 메인 화면과 학생 폰에 키워드·난이도·배점이 크게 나옵니다.
2. 3초가 지나면 문제가 자동으로 열립니다. 기다리기 싫으면 스페이스바로 바로 열 수 있습니다.
3. 답을 공개하고 `선택판으로`를 누르면 그 카드가 **사라지고** 선택판으로 돌아옵니다.
4. 카드를 다 쓰면 자동으로 최종 순위로 갑니다. 시간이 없으면 `퀴즈 마치기`로 중간에 끝낼 수 있습니다.

카드를 고르기 귀찮으면 선택판에서 **스페이스바**만 눌러도 됩니다. 남은 문제 중 번호가 빠른 것부터 열립니다.

---

## 배경음악과 효과음

소리는 모두 대시보드 컴퓨터에서만 나고, 학생 폰은 진동만 합니다.

| 장면 | 음악 |
|---|---|
| 대기실 | 고요한 아침 (자작곡) → 나 같은 죄인 살리신 (Amazing Grace, 1835) 번갈아 |
| 선택판·순위 | 기쁨의 노래 (자작곡) |
| 문제 풀이 | 생각하는 시간 (자작곡) |
| 미니게임 | 달려라 (자작곡) |
| 최종 순위 | 대팡파레 → 기뻐하며 경배하세 (Ode to Joy, 베토벤) |

답 공개·순위·미니게임 완주·다음 문제 예고에는 각각 다른 팡파레가 나옵니다.

**저작권:** 음악은 `public/music.js` 안에서 실시간으로 연주됩니다. 자작곡 4곡은 이 프로그램을 위해 만든 것이고, 찬송가 2곡은 작곡자 사망 후 70년이 훨씬 지나 저작권이 소멸된 곡을 새로 편곡한 것입니다. 외부 음원 파일을 전혀 쓰지 않으니 교회에서 마음껏 쓰셔도 됩니다. `미리듣기` 폴더에 각 곡을 mp3 로 뽑아 두었으니 먼저 들어 보세요.

**내 음악 쓰기:** 원하는 CCM 음원이 있으면 `public/music` 폴더에 넣으세요. 서버를 켤 때 자동으로 읽어서 **그 장면의 자체 연주 대신** 재생합니다. 파일 이름 앞에 장면을 붙이면 됩니다.

| 파일 이름 예 | 나오는 장면 |
|---|---|
| `lobby-찬양1.mp3` (또는 아무 이름) | 대기실 |
| `board-찬양2.mp3` | 선택판·순위 |
| `quiz-잔잔한곡.mp3` | 문제 풀이 |
| `game-빠른곡.mp3` | 미니게임 |
| `final-축하곡.mp3` | 최종 순위 |

같은 장면에 여러 곡을 넣으면 차례로 재생됩니다. 파일은 대시보드가 열릴 때 미리 내려받아 두므로 장면이 바뀌면 바로 나옵니다. 팡파레와 효과음은 그대로 자체 연주가 나옵니다. mp3, m4a, ogg, wav 를 쓸 수 있고, **음원의 저작권은 넣는 분이 확인해 주세요.** 화면 아래 `♫ 음악` / `효과음` 버튼과 음량 슬라이더, `⏭`(다음 곡)으로 조절합니다.

## 접속 주소와 QR

QR과 접속 주소는 **대시보드를 연 브라우저의 주소를 그대로** 보여줍니다. 주소창에 `192.168.0.31:3000` 처럼 치고 들어왔다면 학생들도 같은 주소로 들어옵니다.

다만 `localhost:3000` 으로 열면 학생 폰이 그 주소로는 못 들어오므로, 자동으로 와이파이 주소로 바꿔서 보여주고 화면에 안내 문구가 뜹니다.

---

## 답 공개 화면

`답 마감하고 공개`를 누르면 **같은 답끼리 한 장의 카드로 묶여서** 나옵니다. 카드에는 답과 그 답을 쓴 인원수만 나오고, **누가 썼는지는 표시되지 않습니다.** 50명이 참여해도 카드는 서로 다른 답의 개수만큼만 생기니 화면이 잘리지 않습니다.

- 정답으로 처리된 카드는 초록으로 켜지고 앞쪽에 모입니다.
- **카드를 클릭하면 그 답을 쓴 사람 전체가 한 번에 정답 처리**됩니다. 다시 누르면 취소됩니다.
- 객관식은 보기별 인원수가 나오고, 보기를 클릭해서 정답 처리를 바꿀 수 있습니다.

## 점수 바꾸기

점수는 **기본 점수 × 난이도**로 정해지고, 화면 아래 점수판에서 언제든 바꿀 수 있습니다.

| 난이도 | 배율 | 기본 100점일 때 |
|---|---|---|
| ★ 쉬움 | 1배 | 100점 |
| ★★ 보통 | 1.5배 | 150점 |
| ★★★ 어려움 | 2배 | 200점 |

- 대기실·선택판에서는 `기본 점수 (★★)`가 보입니다. 여기서 바꾸면 모든 문제에 적용됩니다.
- 예고 화면이나 문제가 열려 있을 때는 `12번 점수`처럼 바뀝니다. 여기서 바꾸면 **그 문제만** 달라집니다.
- `-50 / -10 / +10 / +50` 버튼이나 **↑ ↓ 방향키**로 조절합니다.
- 답을 공개한 뒤에 바꿔도 점수가 즉시 다시 계산됩니다.

속도 보너스(정답자 중 1등 +50 … 5등 +10)는 그대로 따로 붙습니다.

## 대기실 점프 게임

학생이 입장하면 대기 화면에 **양 점프** 게임이 뜹니다. 화면을 누르면 양이 뛰고, 돌에 부딪히면 끝납니다. 아이들이 다 들어올 때까지 심심하지 않게 하려는 용도입니다.

최고 기록은 대시보드 대기 화면에 순위로 뜹니다. 퀴즈 점수와는 **전혀 상관없습니다.** 선생님이 `퀴즈 시작`을 누르면 게임은 자동으로 사라지고 첫 문제가 열립니다.

---

## 미니게임

미니게임 카드가 6장 있습니다. 게임이 시작되면 화면과 폰이 **보라색으로 확 바뀌어서** 분위기가 전환됩니다.

대시보드에는 **완주 순위가 실시간으로 쌓이고**, 오른쪽에 참가자 전원의 진행률 막대가 채워집니다. 누가 앞서가는지 다 같이 보면서 응원할 수 있습니다.

| 게임 | 내용 | 시간 |
|---|---|---|
| **기억력 카드 뒤집기** | 카드 16장 중 같은 말씀 짝 8쌍 찾기 (방주, 십자가, 비둘기, 물고기, 왕관, 떨기나무, 무지개, 만나) | 100초 |
| **성경 순서 맞추기** | 섞인 사건을 성경 순서대로 누르기. 구약의 흐름 → 예수님의 생애 → 성경 순서, 세 세트 통과 | 100초 |
| **66권 스피드 탭** | 화면에 뜨는 이름 중 진짜 성경책만 누르기. 가짜(모세서, 다윗기, 솔로몬복음…)를 누르면 하나 깎임. 15개 모으면 완주 | 30초 |
| **말씀 빈칸 채우기** | 유명한 말씀의 빈칸에 들어갈 단어를 4개 중 고르기. 8구절 통과 | 90초 |
| **베드로의 물고기 잡기** | 왔다 갔다 하는 표시가 초록 구간에 있을 때 누르면 한 마리. 잡을수록 빨라지고 구간이 좁아짐. 10마리 완주 | 70초 |
| **이름 글자 맞추기** | 섞인 글자를 순서대로 눌러 성경 인물 이름 완성 (느부갓네살, 멜기세덱…). 8명 통과 | 90초 |

카드 배치와 문제 순서는 **모두에게 똑같이 나옵니다.** 서버가 같은 값을 뿌려서 운으로 갈리지 않습니다.

점수는 **완주한 순서**대로 1등 250점, 2등 240점… 이렇게 10점씩 줄고 최소 100점입니다. 시간 안에 못 끝내도 진행한 만큼 최대 80점까지 받습니다. 시간이 다 되면 자동으로 마감되고, 급하면 `게임 마감` 버튼으로 먼저 끊어도 됩니다.

## 문제 파일 고치기

`questions.json`에서 수정합니다. 고친 뒤 대시보드 오른쪽 아래 `처음으로`를 누르면 다시 읽힙니다.

문제마다 `category`(선택판에 보이는 키워드)와 `difficulty`(1~3, 별 개수)를 적습니다. 키워드는 아무 말이든 됩니다 — 지금은 인물·장소·사건·숫자·말씀·성경책·넌센스를 썼습니다. 빠뜨리면 키워드는 "성경"(넌센스 문제는 "넌센스"), 난이도는 2로 들어갑니다. 점수는 파일에 적지 않고 대시보드에서 정합니다.

**객관식** — `answerIndex`는 **0부터** 셉니다. 첫 번째 보기가 정답이면 0입니다.

```json
{ "type":"choice", "kind":"bible", "category":"인물", "difficulty":2, "text":"…?",
  "options":["가","나","다","라"], "answerIndex":2, "reference":"마 10:2" }
```

**주관식** — `kind`를 `nonsense`로 하면 넌센스 문제(붉은 화면)가 됩니다.

```json
{ "type":"short", "kind":"nonsense", "category":"넌센스", "difficulty":1, "text":"…?",
  "answer":"물고기", "alternates":["생선"], "hint":"…" }
```

**미니게임** — 이 한 줄만 끼워 넣으면 선택판에 보라색 카드로 나옵니다. 순서는 상관없습니다. 선생님이 고르는 시점에 열립니다.

```json
{ "type":"minigame", "game":"memory" }
```

`game`에는 `memory`, `order`, `speed`, `verse`, `catch`, `scramble` 중 하나를 씁니다. 같은 게임을 두 번 넣어도 됩니다.

## 점수 정리

| 항목 | 점수 |
|---|---|
| 문제 정답 | 기본 점수 × 난이도 (100 / 150 / 200) — 점수판에서 조절 |
| 속도 보너스 | 정답자 중 1등 +50, 2등 +40 … 5등 +10 (버튼으로 끌 수 있음) |
| 미니게임 완주 | 1등 250점부터 10점씩 감소, 최소 100점 |
| 미니게임 미완주 | 진행률에 비례해 최대 80점 |

## 그 밖에

- 음악과 효과음은 아래 `♫ 음악` / `효과음` 버튼으로 각각 끌 수 있습니다.
- 학생 폰은 정답이면 초록빛, 오답이면 붉은빛으로 번쩍이고 진동합니다.
- 폰을 새로고침해도 이름과 점수가 유지됩니다. 미니게임 도중 새로고침하면 처음부터 다시 하게 되니 학생들에게 미리 알려 주세요.
- 대기실에서 학생 이름표를 **두 번 클릭**하면 내보낼 수 있습니다.
- 참가자가 많으면 이름표가 작아지고, 넘치면 그 칸만 스크롤됩니다.
- 끝나면 폴더에 `결과_날짜.csv`가 저장됩니다.

## 안 될 때

| 증상 | 해결 |
|---|---|
| 학생 폰 접속 안 됨 | 같은 와이파이 확인 → 방화벽에서 3000번 포트 허용 |
| `EADDRINUSE` | 이미 켜져 있습니다. 기존 명령창을 닫고 다시 실행 |
| 소리가 안 남 | 시작 화면을 클릭했는지 확인. 그래도 안 나면 `♫ 음악` 버튼을 한 번 끄고 다시 켜기 |
| 내 mp3 가 안 나옴 | 파일이 `public/music` 폴더에 있는지, 이름 앞에 장면 접두어가 맞는지 확인하고 서버 재시작 |
| 미니게임이 안 뜸 | 학생 폰을 새로고침하면 현재 진행 중인 게임으로 들어갑니다 |
